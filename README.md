# BOSS岗位研究 · Codex工具包

**研究什么岗位，由你自己填。** 通过普通Chrome扩展连接已登录的BOSS直聘与Codex，读取真实JD、核验职责、去重分类，输出Excel数据和离线HTML行业分析。

岗位、行业、城市、有效样本数量、纳入/排除条件和关注重点都可自定义。产品、销售、财务、护士、技术或AI训练师等可以使用同一套流程；实际纳入以JD职责为准，不保证某个目标能取得指定数量。

## 下载与安装

本仓库提供**完整源码安装包及使用入口**。插件的多层源码目录完整保存在下方ZIP中。

1. **[下载完整源码安装包](./BOSS岗位研究_通用GitHub源码包.zip)**，在文件页面点击下载原始文件。不要只复制网页文字。
2. 右键“全部解压缩”，进入解压后的`boss-research`文件夹，里面应有`.agents`、`plugins`和`chrome-extension`。
3. 双击`先看这里_逐步安装教程.html`，逐步安装Codex本地插件与Chrome扩展。**不要直接把本GitHub仓库根目录当作本地插件市场，先解压完整源码包。**
4. 在Codex打开解压后的源码目录，把`01_安装连接_发给Codex.txt`内容发给它，检查环境、启动本机服务、取得自己的六位连接码。
5. 自己在BOSS登录并查看完整岗位，在该标签页打开研究扩展，输入连接码，点“连接并交给Codex”；先核验一份真实JD。
6. 双击`填写研究需求.html`，填写岗位、行业、城市、数量和重点，生成完整提示词，发给已连接的Codex。先试采最多10份，确认后继续到自己的有效目标。

**GitHub直接打开HTML一般显示源码。请下载到电脑后用浏览器打开。** 仓库根目录的HTML/TXT也可单独下载查看；真正安装仍须完整源码包。

## 使用者可以填什么

| 配置 | 示例 |
|---|---|
| 目标岗位 | 产品经理、销售经理、会计、护士、AI训练师 |
| 行业 | 医疗器械、新能源汽车、互联网，或不限 |
| 城市 | 上海、杭州，或先调研筛选重点城市 |
| 有效样本量 | 100、300、500，可自行填写 |
| 职责范围 | 纳入真实产品规划，排除纯项目实施等 |
| 关注重点 | 证书、薪酬提成、技能门槛、轮班、管理层次、外包驻场 |
| 交付 | Excel＋离线HTML，或单选 |

填写页只在本地生成提示词和research.json，不访问BOSS、不启动采集，也不需要额外部署服务器。通用预筛器没有写死AI关键词或销售排除；如果研究销售，销售就是目标岗位。管理岗符合职责范围仍纳入，并另标层次。

## 安装包包含

- Codex本地插件0.3.0（含本地市场描述、技能、Python采集与CSV处理脚本）。
- Chrome普通扩展0.2.0，使用自己的现有BOSS标签页，不连接调试器、不要求Playwriter。
- 本机桥接服务，只监听`127.0.0.1:19763`，首次生成自己的配对码。
- 通用需求填写页、完整通用研究提示词、详细安装与故障恢复教程。
- AI训练师完整研究示例、配置样例和源码SHA256校验清单。

## 运行要求与数据边界

Windows教程，需要可执行本地任务的Codex客户端、自己的Chrome/BOSS登录、Python3.10+（先查本机或Codex可用运行时）。基础采集和CSV使用Python标准库；xlsx和HTML报告由Codex使用当前环境工具制作。模型分析会使用自身账号额度。

这是非官方工具，不投递简历、不联系招聘者、不读取Cookie或密码、不绕过登录/验证码。遇限制会暂停，使用者自己正常处理。网站结构可能变化，接收者必须先验证真实页面；本地代码检查通过不等于已经在所有电脑、账号验收成功。

完整详情不自动等于有效岗位；需读JD职责、核验状态并去重。区分有效、相邻、排除、证据不足和未复核，目标500有效不等于抓500个页面。薪酬单位、岗位人数、发布日期、外包与驻场地址均据原文，不猜。

本仓库及源码包不含原用户招聘数据、账号、登录态、配对码或长令牌。各人独立登录配对。运行数据在任务work/outputs目录，不提交GitHub。扩展仅传本机服务；交给Codex分析的内容可能由模型服务处理。

电脑休眠、浏览器关闭、服务停止、额度或审核队列会影响长任务。脚本运行不等于AI持续核验；定时回查需要真的创建受支持的自动任务。
